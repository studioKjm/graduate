# 지도 로딩 문제 해결 가이드

## 발견된 문제

1. **초기 로딩 실패**: 지도 페이지를 직접 방문하면 지도가 로드되지 않음
2. **관리자 페이지 방문 후 정상 작동**: 관리자 페이지를 한 번 방문하면 지도가 정상 작동
3. **새로고침 시 다시 실패**: 페이지를 새로고침하면 다시 로딩 실패

## 원인 분석

1. **타이밍 문제**: 컴포넌트 마운트와 API 클라이언트 초기화 타이밍 불일치
2. **초기화 순서**: `isMounted` 상태가 설정되기 전에 API 호출이 발생할 수 있음
3. **네트워크 에러 처리 부족**: 일시적인 네트워크 에러 시 재시도 로직 부족

## 적용된 수정사항

### 1. 마운트 체크 강화
- 브라우저 환경 확인 추가 (`typeof window !== 'undefined'`)
- API 클라이언트 초기화 확인 로그 추가

### 2. 초기화 지연 추가
- 초기 데이터 로딩을 100ms 지연시켜 API 클라이언트가 준비되도록 보장

### 3. 자동 재시도 로직
- 네트워크 에러 발생 시 3초 후 자동 재시도
- API 호출 시 최대 3회 재시도 (지수 백오프 적용)

### 4. 에러 핸들링 개선
- 네트워크 에러와 일반 에러 구분
- 사용자에게 명확한 에러 메시지 표시
- 로딩 상태와 에러 상태를 함께 표시

### 5. 중복 코드 제거
- 중복된 `isMounted` 체크 제거
- 로딩 상태 통합

## 테스트 방법

### 1. 정상 동작 확인
```bash
# 백엔드 서버 실행 (8001번 포트)
cd /Users/jimin/graduate/capitalflow/backend
./start_server.sh

# 프론트엔드 서버 실행
cd /Users/jimin/graduate/capitalflow/frontend
npm run dev
```

### 2. 테스트 시나리오

**시나리오 1: 직접 접속**
1. 브라우저에서 `http://localhost:3000/map` 직접 접속
2. 지도가 정상적으로 로드되는지 확인
3. 콘솔에서 다음 로그 확인:
   - `🔧 API 클라이언트 초기화 확인: ...`
   - `🚀 Initializing all years data at once...`
   - `✅ GeoJSON loaded successfully`
   - `✅ All years data loaded successfully`

**시나리오 2: 새로고침 테스트**
1. 지도 페이지에서 F5 또는 Cmd+R로 새로고침
2. 지도가 정상적으로 다시 로드되는지 확인

**시나리오 3: 네트워크 에러 복구**
1. 백엔드 서버를 일시적으로 중지
2. 지도 페이지 접속 (에러 메시지 확인)
3. 백엔드 서버 재시작
4. 3초 후 자동으로 재시도되어 지도가 로드되는지 확인

## 문제가 계속되는 경우

### 1. 브라우저 콘솔 확인
- 개발자 도구(F12) → Console 탭
- 에러 메시지 확인
- API 호출 로그 확인

### 2. 네트워크 탭 확인
- 개발자 도구(F12) → Network 탭
- `/api/v1/visualization/map-data/` 요청 확인
- 응답 상태 코드 확인 (200이어야 함)

### 3. 백엔드 서버 확인
```bash
# 백엔드 API 직접 테스트
curl http://localhost:8001/api/v1/visualization/map-data/?year=2023
```

### 4. 캐시 클리어
- 브라우저 캐시 클리어
- 하드 리프레시: Cmd+Shift+R (Mac) 또는 Ctrl+Shift+R (Windows)
