## 🗂️ 주요 구성 요소

### 1. Frontend (Next.js)
- **위치**: `capitalflow/frontend/`
- **주요 기능**:
  - App Router 기반 라우팅
  - Mapbox GL JS와 Deck.gl을 이용한 인터랙티브 지도
  - D3.js와 Recharts를 이용한 데이터 시각화
  - Zustand를 이용한 클라이언트 상태 관리
  - React Query를 이용한 서버 상태 관리

### 2. Backend (Django)
- **위치**: `capitalflow/backend/`
- **주요 앱**:
  - `core/`: 핵심 모델 (Countries, Sectors, CapitalTypes)
  - `apps/data/`: 데이터 모델 및 ETL 파이프라인
  - `api/`: REST API 엔드포인트
  - `analytics/`: 데이터 분석 기능
  - `visualization/`: 시각화 데이터 제공
  - `data_management/`: 데이터 관리 UI

### 3. Database (PostgreSQL)
- **주요 테이블**:
  - `countries`: 국가 정보
  - `sectors`: 분야/산업 정보
  - `capital_types`: 자본 타입
  - `raw_capital_data`: 원시 데이터
  - `processed_capital_data`: 정제된 데이터
  - `news_data`: 뉴스 데이터
  - `data_sources`: 데이터 소스 정보
  - `data_processing_logs`: 처리 로그

### 4. Supporting Services
- **Redis**: API 응답 캐싱 및 세션 관리
- **Celery**: 비동기 데이터 수집 및 처리
- **Nginx**: 리버스 프록시 및 SSL/TLS 종료

## 🔄 데이터 파이프라인

```
외부 데이터 소스 (API, 크롤링)
        ↓
데이터 수집 (Celery Tasks)
        ↓
원시 데이터 저장 (RawCapitalData)
        ↓
데이터 정제 및 검증 (Pandas/NumPy)
        ↓
데이터 융합 (가중평균, ML 앙상블)
        ↓
정제된 데이터 저장 (ProcessedCapitalData)
        ↓
Redis 캐싱
        ↓
DRF API 엔드포인트
        ↓
Next.js Frontend 시각화
```

## 🚀 배포 아키텍처

### 개발 환경
- Docker Compose를 이용한 로컬 개발 환경 구성
- Hot reload 지원 (Next.js, Django)
- SQLite (개발용)

### 프로덕션 환경
- Docker 컨테이너 기반 배포
- PostgreSQL 데이터베이스
- Redis 캐싱 계층
- Nginx 웹서버
- Gunicorn WSGI 서버
