# 🔄 Data Flow & Validation

CapitalFlow는 OECD, IMF, World Bank, UN 등 다수의 오픈데이터 소스로부터
경제 및 자본 데이터를 주기적으로 수집·정제·저장합니다.

---

## 📊 Data Flow Structure

```
┌───────────────────────────────────────────────────────────────┐
│ 1. 데이터 수집 (Data Collection)                                │
├───────────────────────────────────────────────────────────────┤
│ • 외부 API 요청 (requests)                                      │
│ • 웹 크롤링 (BeautifulSoup4)                                   │
│ • 뉴스 데이터 수집 (news_crawler.py)                           │
│ • 관리 커맨드 실행 (data_collectors.py)                       │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 2. 원시 데이터 저장 (Raw Data Storage)                          │
├───────────────────────────────────────────────────────────────┤
│ RawCapitalData 모델에 저장                                       │
│ • source (데이터 소스)                                         │
│ • country, sector, capital_type                              │
│ • year (연도)                                                 │
│ • raw_amount, raw_currency                                    │
│ • amount_usd (USD 환산 금액)                                   │
│ • data_quality_score (데이터 품질 점수)                        │
│ • is_estimated (추정 데이터 여부)                              │
│ • confidence_score (신뢰도 점수)                               │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 3. 데이터 정제 및 검증 (Data Cleaning & Validation)             │
├───────────────────────────────────────────────────────────────┤
│ • Pandas를 이용한 데이터 정제                                   │
│ • 누락값 처리 (평균 보간, ML 예측)                              │
│ • 이상치 탐지 및 제거 (평균 ± 3σ)                              │
│ • 단위 통일 (USD 기준)                                         │
│ • 데이터 품질 점수 계산                                        │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 4. 데이터 융합 (Data Fusion)                                    │
├───────────────────────────────────────────────────────────────┤
│ ProcessedCapitalData 모델에 저장                                  │
│ 융합 방법:                                                      │
│ • 가중 평균 (신뢰도 점수 기반)                                  │
│ • ML 앙상블 방법                                               │
│ • 중간값                                                       │
│ • 단일 소스                                                    │
│                                                                 │
│ 생성되는 메타데이터:                                            │
│ • final_amount_usd (최종 USD 금액)                            │
│ • confidence_score (신뢰도 점수)                              │
│ • source_count (참여 소스 수)                                  │
│ • variance (소스 간 분산)                                       │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 5. 데이터베이스 저장 (Database Storage)                         │
├───────────────────────────────────────────────────────────────┤
│ PostgreSQL에 구조화된 데이터 저장                                  │
│ • countries: 국가 정보                                         │
│ • sectors: 분야/산업 정보                                      │
│ • capital_types: 자본 타입                                     │
│ • processed_capital_data: 정제된 자본 데이터                   │
│ • news_data: 뉴스 데이터                                       │
│ • 인덱싱: country + sector + year, year 등                   │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 6. 캐싱 (Redis Cache)                                           │
├───────────────────────────────────────────────────────────────┤
│ • API 응답 캐싱                                                 │
│ • 자주 조회되는 데이터 미리 로딩                                │
│ • 캐시 만료 시간: 1시간                                        │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 7. API 엔드포인트 (DRF API)                                     │
├───────────────────────────────────────────────────────────────┤
│ • GET /api/v1/countries/ - 국가 목록                           │
│ • GET /api/v1/sectors/ - 분야 목록                             │
│ • GET /api/v1/capital-flows/ - 자본 흐름 데이터                │
│ • GET /api/v1/visualization/map/ - 지도 시각화 데이터          │
│ • GET /api/v1/analytics/trends/ - 트렌드 분석                 │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ↓
┌───────────────────────────────────────────────────────────────┐
│ 8. 프론트엔드 시각화 (Next.js Frontend)                         │
├───────────────────────────────────────────────────────────────┤
│ • Mapbox GL JS: 인터랙티브 지도                                 │
│ • Deck.gl: Flow 맵 (국가 간 연결)                              │
│ • D3.js / Recharts: 차트 시각화                                │
│ • 실시간 필터링 및 애니메이션                                  │
└───────────────────────────────────────────────────────────────┘
```

## 🧩 Validation Rules

| 검증항목 | 기준 | 적용 방식 |
|-----------|--------|-------------|
| **결측치** | 5% 미만 | 평균 보간 또는 ML 기반 예측 |
| **단위불일치** | USD 기준 통일 | 단위 변환 모듈 적용 (환율 API 활용) |
| **이상값** | 평균 ± 3σ | 제거 및 로그 기록 |
| **데이터 품질** | 0.0 ~ 1.0 | 신뢰도 점수 기반 가중치 적용 |
| **소스 신뢰도** | 고/중/낮음 | 소스별 가중치 다르게 적용 |
| **추정 데이터** | confidence_score < 0.8 | 추정 방법 및 신뢰도 기록 |

## 🔄 데이터 처리 명령어

### 수집 (Collection)
```bash
# Celery Task를 통한 자동 수집
python manage.py collect_data

# 특정 소스에서 수집
python manage.py collect_data --source WORLD_BANK
```

### 정제 (Cleaning)
```bash
# 데이터 정제 및 검증
python manage.py clean_data

# 특정 연도 데이터 정제
python manage.py clean_data --year 2020
```

### 융합 (Fusion)
```bash
# 다중 소스 데이터 융합
python manage.py fuse_data

# 특정 분야 융합
python manage.py fuse_data --sector MANUFACTURING
```

### 뉴스 수집 (News Collection)
```bash
# 뉴스 데이터 수집
python manage.py collect_news

# 특정 키워드로 수집
python manage.py collect_news --keywords "FDI"
```

## 📊 처리 로그 (DataProcessingLog)

모든 데이터 처리 작업은 `DataProcessingLog` 모델에 기록됩니다:

- **처리 타입**: 수집/정제/융합/검증/예측
- **상태**: 성공/실패/부분 성공
- **결과 정보**: 처리된 레코드 수, 성공/실패 수
- **실행 정보**: 시작/종료 시간, 소요 시간
- **오류 정보**: 오류 메시지

이를 통해 데이터 처리 파이프라인의 투명성과 추적 가능성을 보장합니다.
