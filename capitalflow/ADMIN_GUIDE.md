# CapitalFlow 관리자 대시보드 사용 가이드

## 🚀 접속 방법

1. **웹 브라우저에서 접속**: http://localhost:3000/admin
2. **인증**: 다음 중 하나의 패스워드 입력
   - `admin123`
   - `capitalflow2024`

## 📊 대시보드 구성

### 1. 시스템 개요 (Overview)
- **실시간 통계**: 처리된 데이터, 원시 데이터, 활성 소스 수
- **시스템 상태**: 백엔드 서버 연결 상태 및 건강성
- **빠른 액션**: 자주 사용하는 기능들의 원클릭 실행

### 2. 데이터 관리 (Data Management)
- **데이터 수집**: 외부 소스에서 새로운 데이터 수집
  - 전체 소스 수집
  - 특정 소스별 수집 (IMF, Crunchbase)
- **데이터 융합**: ML 기반 다중 소스 데이터 융합
- **데이터 검증**: 처리된 데이터의 품질 검증

### 3. API 테스트 (API Test)
- **프리셋 엔드포인트**: 주요 API들의 원클릭 테스트
- **커스텀 테스트**: 사용자 정의 엔드포인트 테스트
- **실시간 결과**: 응답 시간, 상태 코드, 데이터 확인
- **배치 테스트**: 모든 GET 엔드포인트 일괄 테스트

### 4. 처리 로그 (Processing Logs)
- **실시간 로그**: 데이터 처리 작업의 실시간 상태
- **상세 정보**: 처리 타입, 성공/실패 건수, 소요 시간
- **오류 추적**: 실패한 작업의 오류 메시지

### 5. 데이터 소스 (Data Sources)
- **소스별 관리**: 각 데이터 소스의 개별 관리
- **신뢰도 시각화**: 소스별 신뢰도 점수 바 차트
- **개별 수집**: 특정 소스만 선택적 데이터 수집

## 🔧 주요 기능

### 데이터 수집 (Data Collection)
```bash
# API 직접 호출 예시
curl -X POST "http://localhost:8001/api/v1/capitalflows/admin/collect/" \
  -H "Content-Type: application/json" \
  -d '{"source": "IMF"}'
```

### 데이터 융합 (Data Fusion)
- **가중 평균**: 소스별 신뢰도 가중치 적용
- **이상치 제거**: Isolation Forest 알고리즘
- **ML 앙상블**: 분산이 큰 경우 머신러닝 융합

### API 엔드포인트 테스트
| 엔드포인트 | 설명 | 예시 |
|------------|------|------|
| `/health/` | 시스템 상태 | 기본 상태 확인 |
| `/metadata/` | 메타데이터 | 국가, 분야, 자본타입 |
| `/capitalflows/` | 자본흐름 데이터 | 필터링 및 집계 |
| `/admin/logs/` | 처리 로그 | 최근 작업 기록 |

## 📈 모니터링 지표

### 시스템 상태
- **Healthy**: 모든 시스템 정상 동작
- **Unhealthy**: 일부 컴포넌트 오류

### 데이터 품질
- **신뢰도 점수**: 0.0 ~ 1.0 (소스별)
- **커버리지**: 데이터 완성도 비율
- **검증 상태**: 품질 검증 통과 여부

### 성능 지표
- **응답 시간**: API 호출 속도 (ms)
- **처리량**: 시간당 처리 레코드 수
- **오류율**: 실패한 작업 비율

## 🚨 문제 해결

### 일반적인 문제들

1. **API 연결 실패**
   - 백엔드 서버 상태 확인: http://localhost:8001/api/v1/capitalflows/health/
   - Django 서버 재시작: `python manage.py runserver 0.0.0.0:8001`

2. **데이터 수집 실패**
   - 로그 확인: 처리 로그 탭에서 오류 메시지 확인
   - 소스별 재시도: 개별 소스 수집 버튼 클릭

3. **융합 작업 실패**
   - 원시 데이터 존재 여부 확인
   - 시스템 리소스 확인 (메모리, CPU)

### 로그 해석

```
처리 타입: COLLECTION
상태: SUCCESS
소스: IMF
성공: 150개 / 실패: 5개
소요 시간: 2분 30초
```
