# 🗓️ CapitalFlow 개발 일정표

본 문서는 CapitalFlow 프로젝트의 전체 개발 일정을 요약한 계획표입니다.  
각 단계는 실제 진행 순서에 따라 6개월 단위로 구성되며, 병렬 개발 구간은 겹쳐서 진행됩니다.

---

## 📆 1단계: 기획 및 데이터 구조 설계 (1개월차)
| 세부 작업 | 기간 | 담당자 | 주요 산출물 |
|------------|--------|-----------|-------------|
| 주제 정의 및 데이터 소스 조사 (World Bank, IMF 등) | 1주 | 김지민 | 데이터 출처 리스트 |
| 국가·분야·자본유형별 데이터 구조 설계 | 1주 | 김지민 | ERD, 스키마 정의서 |
| 기술 스택 선정 및 환경 구성 | 1주 | 김지민 | requirements.txt, Docker 환경 |
| 데이터 수집 테스트 (Python API Request) | 1주 | 김지민 | sample_data.json |

---

## 📆 2단계: 백엔드 개발 (2~3개월차)
| 세부 작업 | 기간 | 담당자 | 주요 산출물 |
|------------|--------|-----------|-------------|
| Django REST Framework API 구축 | 2주 | 김지민 | /api/v1/ 엔드포인트 |
| 데이터 정제 및 통합 로직 구현 (Pandas, NumPy) | 2주 | 김지민 | data_cleaning.py |
| PostgreSQL 연동 및 모델 설계 | 1주 | 김지민 | models.py |
| Redis + Celery 비동기 데이터 수집 파이프라인 | 1주 | 김지민 | tasks.py |
| 데이터 검증 및 테스트 자동화 | 1주 | 김지민 | pytest 스크립트 |

---

## 📆 3단계: 프론트엔드 개발 (3~4개월차)
